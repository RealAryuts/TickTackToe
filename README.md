# Tic-Tac-Toe (Python )

two player tic-tac-toe game built in Python with color coded pieces, custom player names, move history, and a live scoreboard across rounds.

## Features
- **Custom player names:** Enter names for player X and player O before starting.
- **Color coded board:** Distinct colors for `X` (red) and `O` (blue) so the grid is easy to read.
- **Input validation:** Handles invalid characters, out-of-range numbers, and already-occupied spots without crashing.
- **Move history and scoreboard:** Tracks every move made in a round and keeps a running tally of wins and draws across rematches.

## How to Use
- Run `python tictactoe.py` (or open `tictactoe.exe` directly on Windows).
- Enter names for player X and player O.
- Type a number from **1 to 9** to place your `X` or `O` on that spot in the grid.
- Get 3 in a row (across, down, or diagonal) to win the round.
- Type `y` to play another round and update the scoreboard, or `n` to quit.

## Requirements
- Python 3 (if running `tictactoe.py`)
- tactics to defeat opponent
